# Statistical Analysis Report

## Project Title

Statistical Analysis of Experimental Data Using Python

## Objective

The objective of this project is to analyze experimental data using statistical techniques and validate findings quantitatively. The analysis includes measures of central tendency and hypothesis testing.

## Dataset Description

The dataset contains 50 observations divided into two groups:

* Group A (Control Group)
* Group B (Experimental Group)

Each observation represents a score obtained during an experiment.

## Tools Used

* Python
* Pandas
* NumPy
* SciPy

## Statistical Measures Used

### Mean

The mean is the average value of all observations in a dataset.

Purpose:

* Provides a measure of central tendency.

### Median

The median is the middle value when observations are arranged in ascending order.

Purpose:

* Useful when data contains outliers.

### Mode

The mode is the most frequently occurring value.

Purpose:

* Identifies the most common observation.

### Standard Deviation

Standard deviation measures how spread out the values are from the mean.

Purpose:

* Evaluates variability within the dataset.

## Hypothesis Testing

### Null Hypothesis (H₀)

There is no significant difference between the means of Group A and Group B.

### Alternative Hypothesis (H₁)

There is a significant difference between the means of Group A and Group B.

## T-Test Analysis

An Independent T-Test was performed to compare the means of the two groups.

Decision Rule:

* If p-value < 0.05 → Reject the Null Hypothesis
* If p-value ≥ 0.05 → Fail to Reject the Null Hypothesis

## Results

The following statistical measures were calculated:

* Mean
* Median
* Mode
* Standard Deviation
* T-Statistic
* P-Value

The T-Test indicated whether the difference between the groups was statistically significant.

## Interpretation

The p-value obtained from the T-Test was used to determine statistical significance.

A p-value below 0.05 indicates that the observed difference is unlikely to have occurred by chance alone.

## Conclusion

Statistical analysis was successfully performed using Python. Measures of central tendency and hypothesis testing were used to analyze the dataset and draw meaningful conclusions. The results demonstrate how statistical techniques help validate data-driven decisions.

## Interview Questions

### What is a P-Value?

A p-value is the probability of obtaining the observed results assuming that the null hypothesis is true. It helps determine whether results are statistically significant.

### Mean vs Median

Mean is the average of all values, while median is the middle value of an ordered dataset. Median is less affected by extreme values and outliers.

### What is a T-Test?

A T-Test is a statistical method used to compare the means of two groups and determine whether the difference between them is statistically significant.

### Why is Statistical Analysis Important?

Statistical analysis helps identify patterns, validate assumptions, and support data-driven decision-making using quantitative evidence.
