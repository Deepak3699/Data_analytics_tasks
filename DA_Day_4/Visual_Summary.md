# Visual Summary Report

## Project Title

E-Commerce Sales Dashboard using Power BI

## Objective

The objective of this project was to analyze E-Commerce sales data and present business insights through an interactive Power BI dashboard.

## Dashboard Summary

The dashboard was designed to provide a comprehensive overview of sales performance using multiple visualizations and KPI indicators.

### KPI Metrics

The dashboard displays:

* Total Sales
* Total Profit
* Total Orders

These metrics provide a quick overview of overall business performance.

### Sales Trend Analysis

A Line Chart was used to visualize sales over time.

Observation:

* Sales trends can be tracked across different periods.
* Seasonal increases and decreases become visible.

### Category Analysis

A Bar Chart was used to compare sales across product categories.

Observation:

* Some categories generate significantly higher sales than others.
* Category performance can be compared easily.

### Regional Analysis

A Pie Chart was used to display regional sales distribution.

Observation:

* Regions contribute different percentages to total revenue.
* High-performing regions can be identified quickly.

### Profit Analysis

A Column Chart was used to compare profits across categories.

Observation:

* High sales do not always result in high profit.
* Profitability can be evaluated separately from revenue.

### Interactive Filtering

Slicers were added for:

* Region
* Category
* Year

These filters allow users to perform customized analysis and explore specific segments of the data.

## Key Findings

1. Sales performance varies across categories.
2. Regional contributions differ significantly.
3. Certain categories generate higher profits.
4. Sales trends provide useful business insights.
5. Interactive dashboards improve decision-making efficiency.

## Conclusion

The Power BI dashboard effectively communicates business performance through visual storytelling. It enables stakeholders to understand trends, compare performance, and identify opportunities using clear and interactive visualizations.


Q1. Best chart for trends?

Answer:

A Line Chart is the best chart for trends because it clearly shows changes and patterns over time, making it easy to identify growth, decline, and seasonality.

Q2. Dashboard vs Report?

Answer:

Dashboard	               Report
Single-page overview	   Multiple pages
High-level KPIs	           Detailed analysis
Interactive	               More detailed exploration
Quick decision-making	   In-depth reporting

A dashboard provides a high-level summary of key metrics on a single screen, while a report contains detailed data and analysis across multiple pages. Dashboards are used for monitoring, whereas reports are used for deeper investigation.
