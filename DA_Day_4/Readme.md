# E-Commerce Sales Dashboard

## Project Overview

This project focuses on creating an interactive E-Commerce Sales Dashboard using Power BI. The dashboard helps analyze sales performance, profit trends, category-wise performance, and regional sales distribution through visual storytelling.

## Objectives

* Analyze E-Commerce sales data.
* Create meaningful visualizations.
* Build an interactive dashboard.
* Identify business insights and trends.
* Improve decision-making using data.

## Tools Used

* Power BI Desktop
* Microsoft Excel / CSV Dataset

## Dataset Information

The dataset contains information related to:

* Order ID
* Order Date
* Customer Details
* Product Category
* Sub-Category
* Sales
* Profit
* Region

## Dashboard Components

### KPI Cards

* Total Sales
* Total Profit
* Total Orders

### Charts

#### Line Chart

Sales Trend Over Time

Purpose:

* Track sales growth and seasonal patterns.

#### Bar Chart

Sales by Category

Purpose:

* Compare sales performance across product categories.

#### Pie Chart

Regional Sales Distribution

Purpose:

* Show percentage contribution of each region.

#### Column Chart

Profit by Category

Purpose:

* Compare profitability among categories.

### Interactive Features

The dashboard includes slicers for:

* Region
* Category
* Year

These filters allow dynamic exploration of data.

## Key Insights

1. Identified top-performing product categories.
2. Analyzed monthly sales trends.
3. Compared regional sales contributions.
4. Evaluated category-wise profitability.
