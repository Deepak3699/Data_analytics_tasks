## Interview Questions

### Inner Join vs Left Join

INNER JOIN returns only matching records from both tables.

LEFT JOIN returns all records from the left table and matching records from the right table. Non-matching rows return NULL values.

### What is a Subquery?

A subquery is a query nested inside another SQL query. It is used to perform intermediate calculations or filtering.
