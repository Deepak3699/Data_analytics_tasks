## 1. What is EDA?

Exploratory Data Analysis (EDA) is the process of examining, summarizing, and visualizing data before building machine learning models.

Purpose of EDA:
Understand the dataset
Find patterns and trends
Detect missing values
Identify outliers
Understand relationships between variables
Prepare data for further analysis

2. Why Check Correlation?

Correlation measures how strongly two variables are related.

Correlation Values
Value	Meaning
+1	Perfect Positive
 0	No Relationship
-1	Perfect Negative

# Example

If:
Petal Length increases
Petal Width also increases
Then correlation is positive.
