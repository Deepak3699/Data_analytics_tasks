# Customer Segmentation Analysis

## Project Overview

This project performs customer segmentation using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering. The goal is to identify customer groups with similar purchasing behavior and support targeted marketing decisions.

## Dataset

Source: Kaggle Retail Customer Dataset

Features:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Project Workflow

1. Load and preprocess dataset
2. Convert Date column into datetime format
3. Create RFM metrics
4. Standardize RFM features
5. Apply K-Means clustering
6. Generate customer segments
7. Visualize clusters
8. Analyze segment profiles

## Customer Segments

* VIP Customers
* Loyal Customers
* New Customers
* At-Risk Customers

## Deliverables

* Customer Segmentation Python Script
* Segment Report
* Cluster Visualization
* README Documentation

## Outcome

The project successfully segments customers into meaningful groups that can be used for personalized marketing, customer retention, and revenue optimization.

## Interview Questions

### What is RFM?

RFM stands for Recency, Frequency, and Monetary value. It is used to evaluate customer behavior and identify valuable customers.

### What is Customer Segmentation?

Customer segmentation is the process of dividing customers into groups based on similar characteristics and purchasing behavior.

### Why use K-Means?

K-Means is an unsupervised machine learning algorithm that groups similar customers into clusters.

### What is the value of customer segmentation?

* Personalized marketing
* Better customer retention
* Improved customer experience
* Higher revenue generation
* Optimized marketing efforts
